What CIDR notation means

A block like 192.168.1.0/24 is an address and a prefix length. The number after the slash says how many of the leading bits are fixed; the rest are free. IPv4 has 32 bits, so a /24 leaves 8 free: 28 = 256 addresses. Each step down the prefix doubles the block, and each step up halves it.

Questions

What is CIDR notation?

Classless Inter-Domain Routing writes a block of addresses as an address, a slash, and a prefix length: 192.168.1.0/24. The prefix length says how many leading bits are fixed. It replaced the old class A, B and C networks in 1993 and is defined today in RFC 4632.

How many hosts are in a /24?

256 addresses, of which 254 can be given to devices: the first is the network address and the last is the broadcast address. Its netmask is 255.255.255.0.

How many usable hosts are in a /29?

Eight addresses, six usable. A /30 has four addresses and two usable, which is why it was the classic size for a link between two routers - until /31 links became standard.

Why does a /31 have two usable addresses?

A /31 has only two addresses, and on a point-to-point link neither a network address nor a broadcast address is needed, so both are used. RFC 3021 made this standard in 2000.

How do I convert a netmask to CIDR?

Count the 1 bits in the mask. 255.255.255.0 is 24 ones, so /24; 255.255.252.0 is 22 ones, so /22. Type an address and a mask into the calculator above and it does this for you.

How do I turn an IP range into CIDR blocks?

A range only becomes one block if it starts on a boundary of its own size and is a power of two long. Otherwise it needs several. Type the range above, like 10.0.0.0 - 10.0.5.255, and the calculator returns the fewest blocks that cover it exactly.

What is a wildcard mask?

The netmask with every bit flipped: 0.0.0.255 for a /24. Cisco access lists and OSPF use it to say which bits may vary.

How big is an IPv6 subnet?

A /64, almost always: 264 addresses, about 18 quintillion. Automatic address configuration (RFC 4862) depends on that size, so IPv6 networks are not made smaller to save space the way IPv4 ones are.
